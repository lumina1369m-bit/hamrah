# تست‌های همراه

این پوشه همهٔ تست‌های Playwright پروژه را نگه می‌دارد. اجرای همه: `./run_all.sh`

- `login_flow.py <fa|en|ar>`: ورود مسافر تا صفحهٔ اصلی
- `spec_audit.py`: بررسی مشخصات سند مسافر (ورود، نقشه، تقویم، حساب، واکنش‌گرایی)
- `traveler_map_claims_ui.py`: متن سه‌زبانهٔ نقشه بدون شمارش آنلاین، GPS ساختگی یا موفقیت لایهٔ غیرفعال
- `traveler_convert_ui.py`: تبدیل واقعیِ درخواست فوریِ بی‌مترجم به رزرو زمان‌دار؛ بررسی متن سیاست در سه زبان و نبود ادعای شعاع
- `bk_flow.py <en|ar>`: جریان رزرو و بررسی متن فارسی باقی‌مانده
- `account_flow.py <en|ar>`: حساب کاربری
- `photo_flow.py <fa|en|ar>`: آپلود و ذخیره عکس پروفایل
- `map_real.py`: بارگذاری Leaflet و نقشه
- `tr_e2e_full.py <width>`: ورود مترجم تا میز کار (تأیید آزمایشی)
- `tr_missions_e2e.py`: فهرست ماموریت‌های پذیرفته‌شده
- `translator_mission_map.test.js`: ساختار میزکار نمونه‌محور با Leaflet/OpenStreetMap واقعی؛ نمایش نقطهٔ ملاقات فقط از مختصات معتبر سرور و نگه‌داشتن بخش‌های کمکیِ متصل به سرور در دسترس
- `tr_daybar.py`: نوار روزهای تقویم مترجم
- `shots_real.py`: اسکرین‌شات‌ها برای بازبینی بصری

یادداشت: تست‌های `map_toasts.py`، `tr_probe_login.py`، `tr_flow_login.py`، `tr_flow2.py`، `tr_verifyrow.py`، `tr_testapprove.py` ابزارهای بررسی یا تشخیص‌اند و در `run_all.sh` نیستند.

## اجرای به‌روز
- `./run_all.sh` خودش سرور همراه را روی پورت **8081** با پایگاه داده‌ی موقت و `HZ_DEV=1` بالا می‌آورد؛ اپ مترجم در `/translator/` و اپ مسافر در `/traveler/` و API در `/api/` سرو می‌شوند.
- پورت‌های قدیمی ۸۰۹۰ و ۸۰۹۵ دیگر لازم نیستند و در تست‌ها استفاده نمی‌شوند.
- تست API جداگانه: `BASE=http://127.0.0.1:8081 node ../server/test/api.test.js` (سرور را قبلاً با `HZ_DEV=1` بالا بیاورید).
- شماره‌های تلفن تست در هر اجرا تصادفی‌اند تا محدودیت ارسال مجدد و قفل تداخل نکند.
