# تست‌های همراه

اجرای مجموعهٔ جاری: `./run_all.sh`

- `run_all.sh` سرورهای موقت روی پورت‌های ۸۰۸۱ و ۸۰۸۲ و پایگاه دادهٔ تازه بالا می‌آورد؛ آزمون‌های API، پنل مدیر، اپ مترجم و منطق نقشه را اجرا می‌کند.
- `translator_mission_map.test.js`: وضعیت نقشه فقط از مختصات معتبر مأموریت پذیرفته‌شده، بدون مسیر یا GPS ساختگی؛ همچنین حذف رابط مسافر و باقی‌ماندن Leaflet محلی برای مترجم را بررسی می‌کند.
- `tr_e2e_full.py <width>` و `tr_missions_ui.py`: ورود مترجم و میزکار/مأموریت‌ها.
- آزمون‌های API جداگانه را می‌توان با `BASE=http://127.0.0.1:8081 node ../server/test/api.test.js` اجرا کرد؛ سرور باید از قبل با `HZ_DEV=1` بالا باشد.

## وضعیت رابط مسافر

PWA مسافر (`/traveler/`) در این شاخه حذف شده است و این مسیر باید ۴۰۴ برگرداند. APIهای رزرو (`/api/traveler/*`) برای گردش‌کار مترجم حفظ شده‌اند. فایل‌های قدیمی آزمون مرورگری مسافر در پوشهٔ تست‌ها صرفاً برای سابقه باقی مانده‌اند و از `run_all.sh` اجرا نمی‌شوند؛ آزمون‌های مترجم که به رابط مسافر وابسته بودند نیز تا زمان تعریف جریان جایگزین از اجرای پیش‌فرض کنار گذاشته شده‌اند.

شماره‌های تلفن تست در هر اجرا تصادفی‌اند تا محدودیت ارسال مجدد و قفل با هم تداخل نکند.
