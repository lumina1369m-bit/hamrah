# تست‌های همراه

اجرای مجموعهٔ جاری: `./run_all.sh`.

- `run_all.sh` سرورهای آزمایشی روی پورت‌های ۸۰۸۱ و ۸۰۸۲ را با پایگاه دادهٔ تازه بالا می‌آورد و تست‌های API، اپ مسافر، پنل مدیر و صفحات ورود/ثبت‌نام مترجم را اجرا می‌کند.
- `translator_app_removal.test.js`: باقی‌ماندن صفحهٔ ورود/ثبت‌نام مترجم و اپ مسافر، و حذف داشبورد مترجم را بررسی می‌کند.
- `tr_docs_ui.py` و `tr_docs_send_ui.py`: فرم‌های ثبت‌نام و ارسال مدارک مترجم.
- تست API جداگانه: `BASE=http://127.0.0.1:8081 node ../server/test/api.test.js`؛ سرور باید از قبل با `HZ_DEV=1` بالا باشد.

## وضعیت اپ مترجم

`/translator/index.html` و صفحهٔ ورود/ثبت‌نام باقی مانده‌اند. داشبورد پس از ورود و فایل‌های اختصاصی آن حذف شده‌اند؛ بنابراین مقصد فعلی ورود موفق، `app.html`، هنوز صفحه‌ای ندارد و ۴۰۴ می‌دهد تا دربارهٔ مرحلهٔ بعد دستور بگیریم. تست‌های قدیمی داشبورد در پوشهٔ تست‌ها برای سابقه باقی‌اند اما از اجرای پیش‌فرض کنار گذاشته شده‌اند.

## وضعیت اپ مسافر

اپ مسافر بدون تغییر در `traveler/` باقی است. API رزروها نیز برای گردش‌کارهای آن و مترجم حفظ شده‌اند.

شماره‌های تلفن تست در هر اجرا تصادفی‌اند تا محدودیت ارسال مجدد و قفل با هم تداخل نکند.
