# همراه — سورس پروژه

مخزن سورس پروژه‌ی «همراه» (پلتفرم اتصال مسافر نیازمند مترجم به مترجم همراه): سرور، اپ مسافر، اپ مترجم، پنل مدیریت، تست‌ها و مستندات.

## ساختار پوشه‌ها

| پوشه / فایل | محتوا |
|---|---|
| `server/` | سرور Node.js و پایگاه داده‌ی SQLite. فایل اصلی `server.js` است. |
| `server/test/` | تست‌های API و امکانات و شهرها و زمان‌بندی |
| `traveler/` | اپ مسافر (PWA) |
| `translator/` | اپ مترجم (PWA) و میز کار |
| `admin/` | پنل مدیریت (یک صفحه‌ی HTML) |
| `tests/` | تست‌های مرورگر (Playwright). اجرای همه: `./run_all.sh` |
| `legacy/` | دو فایل قدیمی که بیرون از انتشار نگه داشته شده‌اند و سرو نمی‌شوند |
| `docs/` | اسناد Word: سند جامع، سند اپ مترجم، بازبینی‌ها |
| `design/` | مرجع طراحی (خروجی ابزار Stitch) |
| `RELEASE_CHECKLIST.md` | چک‌لیست انتشار و تصمیم‌های ثبت‌شده |

## اجرای سرور

پیش‌نیاز: Node.js نسخه‌ی ۲۰ یا بالاتر.

```bash
cd server
npm install
HZ_DEV=1 HZ_ADMIN_PASSWORD=your-admin-password PORT=8080 node server.js
```

متغیرهای محیطی:

- `PORT`: پورت سرور (پیش‌فرض ۸۰۸۰ در تنظیمات فعلی).
- `HZ_ADMIN_PASSWORD`: رمز آغازین ورود به پنل مدیریت. بدون آن پنل فعال نمی‌شود. مدیر می‌تواند بعداً از داخل پنل (تب «تنظیمات ← تغییر رمز مدیر») رمز را عوض کند؛ رمز تازه به‌صورت هش‌شده در پایگاه داده ذخیره می‌شود و از آن پس همان معتبر است.
- `HZ_DEV=1`: حالت توسعه. کد ثابت پیامک `123456` و ورود آزمایشی مترجم فقط در این حالت فعال است. **در نسخه‌ی واقعی هرگز نگذارید.**
- `HZ_DOC_KEY`: کلید رمزنگاری مدارک مترجمان. در حالت غیرتوسعه **الزامی** است؛ بدون آن سرور اجرا نمی‌شود.
- `HZ_DB`: مسیر فایل پایگاه داده. پیش‌فرض `server/data/hamzaban.sqlite`.

بعد از اجرا:

- پنل مدیریت: `http://localhost:8080/admin/`
- اپ مترجم: `http://localhost:8080/translator/`
- اپ مسافر: `http://localhost:8080/traveler/`

## اجرای تست‌ها

```bash
pip install playwright
python3 -m playwright install chromium
cd tests
./run_all.sh
```

`run_all.sh` دو سرور موقت روی پورت‌های ۸۱۸۱ و ۸۱۸۲ بالا می‌آورد و با پایگاه داده‌ی موقت تست‌ها را اجرا می‌کند. تست‌های API جدا هستند:

```bash
cd server
BASE=http://127.0.0.1:8081 node test/api.test.js
```

## نکته‌های امنیتی و انتشار

- پوشه‌ی `server/data` خالی است. پایگاه داده‌ی توسعه (با داده‌ی آزمایشی) در سورس نیست.
- `node_modules` در سورس نیست؛ با `npm install` ساخته می‌شود.
- کلید `HZ_DOC_KEY` و رمز مدیر را هرگز در کد نگذارید.
- جزئیات کامل وضعیت انتشار در `RELEASE_CHECKLIST.md` آمده است.
